# Decision Trees and Random Forests

## Objective
Build and evaluate Decision Tree and Random Forest classifiers using Python and scikit-learn.

## Dataset
Breast Cancer Wisconsin dataset provided by scikit-learn.

## Models
- Decision Tree Classifier
- Random Forest Classifier

## Evaluation
- Accuracy score
- Classification report
- Feature importance analysis

## Visualizations
- Decision Tree visualization
- Top 10 Random Forest feature importances

## Testing
Basic validation tests verify prediction lengths, valid class labels, and accuracy values.

## Tools
Python, Pandas, Matplotlib, and scikit-learn.

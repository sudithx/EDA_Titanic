
# Week 4: Bias-Variance Tradeoff & Regularisation

## Objective
Understand underfitting, overfitting, and regularisation using Python.

## Tools
- Python
- NumPy and Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Experiments
1. Compared polynomial regression models of degrees 1, 3, and 15.
2. Evaluated training and testing Mean Squared Error (MSE).
3. Applied Ridge (L2) regularisation.
4. Applied Lasso (L1) regularisation.
5. Compared model performance using MSE and R-squared.

## Key Learning
- Underfitting occurs when a model is too simple.
- Overfitting occurs when a model learns noise in the training data.
- Regularisation penalises large coefficients to help control model complexity.
